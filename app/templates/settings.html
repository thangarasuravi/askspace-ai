How Provider Configuration Works

AskSpace AI uses a server-side provider abstraction (app/services/ai_provider.py). No secrets or API keys are ever transmitted to or stored in client JavaScript.

.env (in project root) 
# To activate Google Gemini (Recommended):
AI_PROVIDER=gemini
GEMINI_API_KEY=your_gemini_api_key_here
GEMINI_MODEL=gemini-1.5-flash

# Or to activate OpenAI:
AI_PROVIDER=openai
OPENAI_API_KEY=your_openai_key_here
OPENAI_MODEL=gpt-4o-mini

When no API key is provided, AskSpace AI safely runs in Demo Mode, providing curated answers for MCA curriculum topics, algorithms, and technical interview preparation.
